Welcome to NaC Workflows

Network as Code - Manage your network infrastructure using Infrastrcture as Code

The intent of this tool is to demonstrate what is possible by using NaC-API in front of Network as Code. Operators that struggle with learning data structures (in this case YAML) could potentially use a tool similar to this to create workflows that take advantage of Network as Code to push configuration changes into their network with all the embeded benefits of validation that Network as Code provides.

NaC-API provides means to create a simple front-end towards the data structure used by Network as Code. NaC API interacts with underlying Source Code Managers (SCM) to retrieve and update the data model. NaC API supports Github, Gitlab, Bitbucket and even local file system representation of the model.
